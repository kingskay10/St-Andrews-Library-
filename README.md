Online Library Management System


This project will create an online system that will help manage the  St Andrews Mission Secondary School library. It will only be used by the librarian. 

Main Features of System

1.Book Manager

••Add New Books.
••Edit Book Information.
••View books available to be borrowed.
••Report books damaged or missing.
••View total amount of books.

2.Students manager

••Add New Students.
••Keep student names  and classes.
••View individual student borrowing history.
••Keep names of students who borrowed books.

3.Borrow Manager

••Add students borrowing books.
••Add names of books and dates they were borrowed.
••Set date for books to be returned.
••See current borrowed book.

4.Return Manager

••Add returned books.
••Automatically update books availability.
••Report damage/lost books.


How System Will Work

User logs in as librarian.
When a student borrows a book the librarian will search for their details.
The librarian will select a book and add the borrowing.
The date the book was borrowed and date it should be returned will be stored.
When the student returns their book the librarian will add this.
Automatically update the book availability and students borrowing.
